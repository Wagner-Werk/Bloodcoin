Example data

Each week our server reads US death counts from the CDC, signs them and sends them to the BCUS contract. The contract uses them to set how many new BCUS are created. Every report is listed here with the exact CDC weeks it used, and you can check each one against the CDC directly from your browser, without trusting our server.

Who runs this oracle, and why that matters

The oracle is run by the Bloodcoin founder, who also holds a large amount of BCUS. That is a conflict of interest: whoever reports the numbers influences the emission.

The contract rejects implausible values and limits how far one report can move the factor. A small, plausible-looking change would still be accepted. The protection is that every report is public and anyone can compare it with the CDC. If a report does not match, please say so publicly.

How the number is calculated

Deaths is the sum of US deaths in the 4 weeks up to the report week. 3-year average is the same 4 calendar weeks in each of the previous 3 years, averaged.

Within ±3 % the target factor is 1.0. Beyond that, each further percent of excess deaths lowers it by 0.05, and each percent below the average raises it by 0.05, limited to 0.5 to 1.5. The factor used for emission moves at most 0.05 per report toward the target.

What the contract enforces

  • Only reports signed by the oracle key are accepted.
  • Deaths must lie between 80,000 and 1,000,000.
  • Deaths and 3-year average may differ by at most a factor of two.
  • The factor moves at most 0.05 per report.
  • The factor always stays between 0.5 and 1.5.
  • All parameters are fixed. Nobody can change the contract.

How a report travels

  1. CDC publishesWeekly death counts appear on data.cdc.gov.
  2. Server readsEvery Monday at 12:00 UTC the script fetches the 16 weeks it needs.
  3. Server signsThe figures are signed with the oracle key (EIP-712).
  4. Contract checksSignature and limits are verified before the report is stored.
  5. Published hereThe report and the full CDC answer appear on this page.

Verify without this page

The CDC still revises recent weeks, usually upward by 1–2 %, so a small difference to today's numbers is normal. To check from the command line, download a report and the script that creates it (Python 3, no other dependencies for checking), then run:

python3 report.py verify 2026-08-15.json

Found a report that does not match? Write to contact@bloodcoin-us.com or open an issue on GitHub. Please also say so publicly.
